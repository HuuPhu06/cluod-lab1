Cloud Computing

Cloud computing lets people use resources such as servers, storage, and software over the internet. For example, I can save a document in Google Drive and open it later on my laptop or phone. A university can also use cloud resources to run its course registration website. When registration opens, many students may visit the site at the same time. The university can add capacity during that busy period and reduce it when traffic goes down. It can also track how much it uses to manage costs.

Cloud Services

  • IaaS (Infrastructure as a Service) provides virtual infrastructure such as servers, storage, and networking. For example, with Amazon EC2, I can launch a virtual server and install my own software on it.
  • PaaS (Platform as a Service) provides a managed platform for deploying applications. For example, with AWS Elastic Beanstalk, I can upload my application code and let the platform handle the deployment and underlying infrastructure.
  • SaaS (Software as a Service) provides ready-to-use software over the internet. For example, I can use Google Docs to write and share documents directly in my browser.
